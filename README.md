# MADCOW

Local scout build for the Lions core group, now updated with a three-game team read.

## What is inside

- `index.html`: main scouting page
- `styles.css`: page styling
- `assets/portraits/`: generated player reference cards
- `assets/shots/`: tape stills
- `assets/plots/`: green make / red miss shot charts
- `shot_chart_data.json`: reusable chart points for each player
- `build_shot_charts.py`: rebuild script for the shot chart images
